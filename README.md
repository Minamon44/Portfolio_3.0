# Portfolio 3.0 — Mina Mohsen Azmy

Dark terminal-aesthetic portfolio built with Next.js 16 + Tailwind CSS v4 + Motion.

**Live:** https://minamon44.github.io/Portfolio-3.0

## Stack
- Next.js 16 (static export)
- Tailwind CSS v4
- Motion (Framer Motion)
- JetBrains Mono + IBM Plex Sans
- GitHub Actions → GitHub Pages

## Local dev
```bash
cd Website
npm install
npm run dev
```

## Deploy
Push to `main` — GitHub Actions handles the rest.

## Updating content
All content lives in `Website/src/content/`:
- `hero.ts` — name, tagline, terminal lines, stats
- `projects.ts` — project cards
- `skills.ts` — skill groups
- `education.ts` — degree, certs, languages
- `experience.ts` — roles
- `contact.ts` — email, links
